# Plantilla de bóveda Obsidian

Estructura PKM lista para usar: entrada, cerebro, recursos y mapas de contenido con Dataview y Folder Notes.

## Uso

1. Clona o descarga este repositorio.
2. Abre la carpeta como bóveda en [Obsidian](https://obsidian.md/).
3. Activa los community plugins **Dataview** y **Folder Notes**.
4. Empieza por [[Inicio]].

## Estructura

| Carpeta | Propósito |
|---------|-----------|
| `00-ENTRADA/` | Captura sin procesar |
| `01-CEREBRO/` | Conocimiento, accionables, agenda, identidad |
| `02-RECURSOS/` | Archivos de referencia externos |
| `03-AUTOMATIZACIONES/` | Zona reservada para automatizaciones |
| `04-GENAI/` | Zona reservada para convenciones de IA |

## Plugins recomendados

- **Dataview** — vistas en mapas e Inicio
- **Folder Notes** — notas homónimas como mapas de carpeta
